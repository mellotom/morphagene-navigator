# morphagene-navigator

travelers guide for navigating wormholes: a one-page reference for the make noise morphagene (firmware mg204). every button combo, options.txt setting and activity window color, with diagrams.

live page: https://mellotom.github.io/morphagene-navigator/

compiled from the make noise morphagene manual (changelog through mg203; mg204 is a bug-fix release). splice markers from ableton live: [morpmarker](https://mellotom.github.io/morpmarker/), an m4l device. not affiliated with make noise.
